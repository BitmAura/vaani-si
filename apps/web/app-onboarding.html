Website Embed & CMS Integration Guide

Choose how you wish to install the Punarvaas AEO & GEO script on your website.

WPCode Plugin (2-Minute WordPress Install)
  1. Log in to WordPress admin at punarvaas.com/wp-admin.
  2. Go to Code Snippets → Header & Footer.
  3. Paste the script tag into the Header box: 
    <script src="https://vaani-si-web.vercel.app/geo/loader.js?entity=punarvaas" async></script>
  4. Click Save Changes. Your AI knowledge graph & JSON-LD schemas go live immediately!
Elementor Pro Custom Code
  1. Go to Elementor → Custom Code → Add New.
  2. Set Location to <head> and Priority to 1.
  3. Paste the snippet and click Publish → Entire Site.
Custom HTML / Next.js / PHP Theme

Place the script tag inside the <head> section of index.html or header.php.
