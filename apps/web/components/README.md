# VANNI Web — Components

Linear-grade, obsidian-inspired B2B SaaS components built on top of `@vanni/ui` design tokens:

- `layout/`: AppShell, DashboardSidebar, DashboardHeader, PageHeader.
- `navigation/`: Tabs, Breadcrumbs, Pagination, CommandMenu.
- `voice/`: VoiceActivityIndicator, TranscriptLine, AudioWaveform.
- `analytics/`: MetricCard, Table, Timeline, EmptyState.
- `forms/`: Input, Select, Switch, Textarea, FileUpload.
- `feedback/`: Alert, Badge, StatusDot, SkeletonLoader.
